# Глянь, блядь, не пожалеешь!

Автоматические рекомендации фильмов и сериалов для сообщества VK `243146657`.

## Секреты GitHub

В Settings → Secrets and variables → Actions добавьте:

- `VK_ACCESS_TOKEN` — токен сообщества с правом публикации на стене.
- `VK_GROUP_ID` — `243146657`.

Токен не храните в коде и не отправляйте в переписке.

## Расписание

10 публикаций ежедневно по московскому времени: 08:00, 09:30, 11:00, 12:30, 14:00, 15:30, 17:00, 18:30, 20:00 и 21:30.

GitHub Actions использует UTC cron, поэтому расписание настроено на UTC+3 (Москва).

## Формат

Одно короткое предложение с рекомендацией, затем ровно три хэштега. История в `post_history.json` защищает от повторных фильмов, текстов и повторного запуска одного слота.

Каталог рекомендаций находится в `MOVIES` внутри `main.py`. Когда все названия будут использованы, публикация безопасно остановится, а каталог нужно будет пополнить новыми фильмами и сериалами.
